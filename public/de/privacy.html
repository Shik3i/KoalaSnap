Datenschutzerklärung

1. Hosting & Logfiles

Diese Seite wird auf einem privaten Server gehostet. Standard-Serverlogs (angefragte URL, Uhrzeit, IP-Adresse, User-Agent) werden aus Betriebssicherheitsgründen erfasst und nach 7 Tagen automatisch gelöscht.

2. Keine Cookies & kein Tracking

Diese Website verwendet keine Cookies, Tracking-Pixel, Analysedienste, Fingerprinting oder andere Formen der Datenerfassung durch Dritte. Wir haben kein Interesse daran, wer Sie sind oder was Sie auf dieser Website tun.

3. Ausschließlich Local Storage

Der Editor verwendet ausschließlich den localStorage Ihres Browsers, um Ihre Einstellungen (Theme, Texte, Konfiguration) zu speichern. Keine Daten aus localStorage werden an einen Server übertragen – sie verlassen niemals Ihr Gerät.

4. Volle Client-Seite

KoalaSnap läuft vollständig in Ihrem Browser. Sämtliches Rendering, die Bildverarbeitung und der PNG-Export erfolgen clientseitig. Es gibt kein Backend, keine Datenbank und kein Benutzerkonto. Es werden keine Daten auf einen Server hochgeladen, gespeichert oder verarbeitet.

5. Open Source

KoalaSnap ist 100 % Open Source. Jede Zeile Code kann öffentlich auf GitHub eingesehen und geprüft werden.

6. Ihre Rechte

Sie haben das Recht auf Auskunft, Berichtigung oder Löschung Ihrer Daten. Da der Editor sämtliche Daten ausschließlich im localStorage Ihres Browsers speichert, können Sie diese jederzeit über die Browser-Einstellungen oder die "Reset"-Funktion im Editor löschen.
